# Weather App

This is a simple Weather App created using React.
It uses the OpenWeatherMap API to get weather details.
Users can search for the weather by entering a city name.
The app shows temperature, humidity, wind speed, and weather description.
It also shows the feels-like temperature.
I added input validation for the city name.
The validation prevents empty or invalid city names.
I used HTML, CSS, JavaScript, and React for this project.
This project helped me learn API integration and React basics.
